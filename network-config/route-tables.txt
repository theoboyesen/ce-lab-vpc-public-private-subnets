Route Table Name: public-rt

Associated Subnets:
- public-subnet-a
- public-subnet-b

Routes:
- Destination: 0.0.0.0/0
  Target: Internet Gateway

Behavior:
Allows outbound internet access for resources in public subnets.


Route Table Name: private-rt

Associated Subnets:
- private-subnet-a
- private-subnet-b

Routes:
- No default route (0.0.0.0/0) to Internet Gateway

Behavior:
Ensures private subnets remain isolated from the internet.
